0. Projet (fichier .json) et import Pléiades (.slk)

Plusieurs fichiers possibles (1 par bâtiment) - s'ajoutent au projet
Glissez-déposez ici un ou plusieurs fichiers .slk (déperditions Pléiades, 1 par bâtiment) - ils s'ajoutent au projet. Ou un fichier projet .json.
Un projet = un fichier .json (pièces, régime, choix manuels, catalogue). "Enregistrer" écrit dans le fichier et, sur les navigateurs compatibles, se synchronise directement avec le même fichier à chaque enregistrement.
